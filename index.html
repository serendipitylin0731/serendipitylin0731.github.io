01 / ANDROID

轨迹 · 铁路出行规划Trajectory · Railway Trip Planner

独立开发的 Web 与 Android 铁路出行规划工具；支持多组出发、到达及有序途径站，按日期查询 12306 实际车次，规划直达或最多 3 次换乘；结果分直达和中转展示，社区静态时刻表仅辅助搜索。An independently developed Web and Android railway planner with multiple departure and arrival groups and ordered via stops. It queries real 12306 trains, supports up to three transfers, separates direct and connecting results; static timetables only aid search.
